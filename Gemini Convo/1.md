# Open-Source CLI Security Audit Tools & CodeRabbit Alternative Pipeline

This document compiles the complete technical logs, iterative architectural evolution, bash audit scripts, scanner outputs, and vulnerability remediation guidelines from the security audit session on the `crumb.elixpo` codebase.

---

## Executive Summary & Tool Evolution

The project's objective was to develop an autonomous, open-source, local command-line security auditing engine that mirrors and surpasses commercial automated code review platforms like **CodeRabbit** without relying on external cloud SaaS APIs.

### The Pipeline Architecture Stack

| Stage | Tool | Focus / Scope | Output / Integration |
| :--- | :--- | :--- | :--- |
| **0. Elevation & Env** | Bash / Sudo | Privilege elevation, daemon management, trap cleanup | Interactive terminal UI |
| **1. AI Daemon** | Ollama | Local LLM hosting (`gemma4:e4b` $\to$ `qwen2.5-coder:1.5b`) | REST API on localhost (`11434`) |
| **2. Multi-Linters** | Cargo Clippy, Ruff, Biome | Language-native AST analysis (Rust, Python, TS/JS) | Diagnostic logs fed into LLM prompt |
| **3. Secret Detection**| Gitleaks | High-entropy tokens, private keys, API credentials | Line-by-line leak fingerprints |
| **4. Deep SAST** | Semgrep | Code execution flaws, tainted input, CI/CD misconfigs | Rule-based blocking security findings |
| **5. SCA / Dependencies**| Trivy | Cargo (`Cargo.lock`) and Node (`package-lock.json`) CVEs | Vulnerability & license database matching |
| **6. AI Reviewer** | Qwen2.5-Coder (1.5B) | Linter triage, noise filtering, committable unified diffs | Markdown reports & `.patch` blocks |
| **7. Delta Tracking** | Custom Timeline Engine | Progression tracking across audit runs | `reports/timeline.md` |

### 2. Secret Scanner Findings (Gitleaks)

The initial scan detected **78 findings**, classified into two main categories:

#### A. Redaction Logic False Positives
The security utility crates (`crumb-tools` and `crumb-optimize`) contain pattern-matching algorithms to sanitize credentials in terminal logs. Gitleaks flagged the matching patterns themselves as hardcoded secrets:
* **`crates/crumb-tools/src/checkpoint.rs:392`**: Matcher for `-----BEGIN PRIVATE KEY-----` (Entropy: 4.2358)
* **`crates/crumb-optimize/src/lib.rs:268`**: Matcher for `-----begin private key-----` (Entropy: 3.8699)

```rust

        .iter().any(|marker| compact.contains(marker));

        output.push_str("[sensitive output redacted]
```

#### B. Documentation & Example Credentials
* **Documentation files**: `.github/docs/pollinations_ai.md`, `docs/reference/pollinations.md`
* Hardcoded curl examples containing dummy credentials:
  * `Authorization: Bearer YOUR_API_KEY` (RuleID: `curl-auth-header`, Entropy: 3.2516)
  * `sk_yoursecretkey` (RuleID: `curl-auth-header`, Entropy: 3.2028)
  * `api_key=sk_abc123xyz` (RuleID: `generic-api-key`, Entropy: 3.5849)

### 3. Static Application Security Testing (Semgrep - 114 Findings)

#### A. Supply Chain: Mutable GitHub Actions Tags
All workflow files pinned GitHub Actions using mutable tags (`@v4`, `@v5`, `@v7`, `@v9`) rather than immutable 40-character commit SHAs.
* **Impact**: Susceptible to supply-chain tampering if upstream repositories or release tags are maliciously repointed.
* **Affected Workflows**:
  * `artifact-update.yml` (`actions/checkout@v4`, `actions/setup-python@v5`, `actions/upload-artifact@v4`)
  * `ci.yml` (`dtolnay/rust-toolchain@stable`, `Swatinem/rust-cache@v2`)
  * `deploy.yml`, `elixpo-agent.yml`, `elixpo-triage.yml`, `on-merge.yml`, `quality-gate.yml`, `release-gate.yml`

#### B. Principle of Least Privilege: Secret Inheritance
* **Location**: `.github/workflows/elixpo-ci.yml:30, 37, 42`
* **Rule**: `yaml.github-actions.security.secrets-inherit.secrets-inherit`
* **Issue**: Reusable workflows called with `secrets: inherit`, granting full exposure to all repository secrets rather than explicit scoping.

#### C. Arbitrary Code Execution via `globals()`
* **Locations**:
  * `.github/scripts/build_artifact.py:12, 111, 112`
  * `.github/scripts/merge_gist.py:27, 84`
* **Rule**: `python.lang.security.dangerous-globals-use.dangerous-globals-use`
* **Pattern**: `REPO = os.environ.get("REPO") or globals().get("REPO", "")`
* **Risk**: Indexing into Python's `globals()` using dynamically evaluated inputs can allow arbitrary code execution.

#### D. Arbitrary File Read / SSRF via `urllib`
* **Location**: `.github/scripts/_common.py:115, 152, 202`
* **Rule**: `python.lang.security.audit.dynamic-urllib-use-detected`
* **Pattern**: `urllib.request.urlopen(req, timeout=DEFAULT_TIMEOUT)`
* **Risk**: Python's `urllib` transparently supports `file://` URIs; unvalidated dynamic URLs enable local file read vulnerabilities.

#### E. Missing Dependabot Cooldown
* **Location**: `.github/dependabot.yml:3, 10`
* **Rule**: `package_managers.dependabot.dependabot-missing-cooldown`
* **Risk**: Missing `cooldown: default-days: 7` allows newly published and potentially poisoned upstream packages to be imported immediately.

### 4. Architectural Analysis of `crumb-agent` (AI Code Review)

The initial LLM review analyzed the core Rust domain structures within the `crumb-agent` crate:

```text
crumb-agent/
├── src/
│   ├── approvals.rs   # Bounded bridge for human-in-the-loop decisions (digests only)
│   ├── backend.rs     # Executable command discovery & validation
│   ├── config.rs      # AgentConfig strongly typed specification
│   ├── harness.rs     # Subprocess/Native turn execution harness
│   ├── jobs.rs        # Time-series lifecycle state machine (JobSchedule, JobState)
│   ├── lib.rs         # Clean facade re-exporting public API contracts
│   ├── routing.rs     # Deterministic non-AI input parser (CommandCatalog, RoutePolicy)
│   ├── session.rs     # Event-sourced auditable logs (sanitized digests only)
│   ├── steering.rs    # Bounded in-memory follow-up message buffer (SteeringQueue)
│   └── tools.rs       # External capability contracts with mandatory RiskClass enum
```

#### Core Design Strengths & Recommendations:
1. **Sanitization & Immutability**: `SessionEvent` and `ApprovalRequest` intentionally avoid persisting or printing raw credentials and full prompts, relying exclusively on SHA-256 argument digests.
2. **Display Traits**: Implement `std::fmt::Display` for `RouteReason` in `routing.rs` for frictionless terminal logging.
3. **Queue Inspection**: Provide a non-destructive `peek(&self) -> Option<&str>` on `SteeringQueue`.
4. **Custom Error Handling**: Migrate internal libraries from loose `anyhow::Result` to structured, domain-specific `thiserror` enums.

## Part 4: Complete Upgraded Script (`audit_codebase.sh` - Final Production Version)

This final version fixes:
1. Argument ordering in `find` (placing `-maxdepth` before `-name`).
2. Regex syntax escaping in `grep` when parsing Semgrep output.
3. Lightweight AI integration with `qwen2.5-coder:1.5b`.
4. Multi-language linter orchestration across Rust, JS/TS, and Python.

while true; do

${BLUE}----------------------------------------${NC}"
echo -e "${BLUE}[5/5] Generating CodeRabbit-Style AI Review (${MODEL_NAME})...${NC}"
echo -e "${BLUE}----------------------------------------${NC}"

DIFF_CONTEXT=""
if [ -d "$TARGET_DIR/.git" ]; then

TIMELINE_HEADER
fi

if [ -n "$PREV_LINE" ]; then
    PREV_LINT=$(echo "$PREV_LINE" | awk -F'|' '{print $4}' | tr -d ' ')
    PREV_SECRETS=$(echo "$PREV_LINE" | awk -F'|' '{print $5}' | tr -d ' ')
    PREV_SAST=$(echo "$PREV_LINE" | awk -F'|' '{print $6}' | tr -d ' ')
    PREV_CVE=$(echo "$PREV_LINE" | awk -F'|' '{print $7}' | tr -d ' ')

    DIFF_LINT=$((LINTER_ISSUES - PREV_LINT))
    DIFF_SECRETS=$((SECRET_COUNT - PREV_SECRETS))
    DIFF_SAST=$((SAST_COUNT - PREV_SAST))
    DIFF_CVE=$((TRIVY_COUNT - PREV_CVE))

    DELTA_PARTS=()
    [ "$DIFF_LINT" -gt 0 ] && DELTA_PARTS+=("+$DIFF_LINT Lint")
    [ "$DIFF_LINT" -lt 0 ] && DELTA_PARTS+=("$DIFF_LINT Lint")
    [ "$DIFF_SECRETS" -gt 0 ] && DELTA_PARTS+=("+$DIFF_SECRETS Secrets")

    [ "$DIFF_CVE" -gt 0 ] && DELTA_PARTS+=("+$DIFF_CVE CVEs")
    [ "$DIFF_CVE" -lt 0 ] && DELTA_PARTS+=("$DIFF_CVE CVEs")

    if [ ${#DELTA_PARTS[@]} -eq 0 ]; then
        DELTA_STR="No Changes"
    else
        DELTA_STR=$(IFS=', '; echo "${DELTA_PARTS[*]}")
    fi
fi

echo "${TIMESTAMP} | $HUMAN_DATE | $LINTER_ISSUES | $SECRET_COUNT | $SAST_COUNT | $TRIVY_COUNT | $DELTA_STR | [detailed](detailed_audit_report_${TIMESTAMP}.md) | [summary](summary_audit_report_${TIMESTAMP}.md) |" >> "$TIMELINE_FILE"

# 10. Clean temp files
rm -f "$LINTER_LOG" "$GITLEAKS_RAW" "$SEMGREP_RAW" "$TRIVY_RAW" "$OLLAMA_RAW"
